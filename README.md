# Статическая копия leoklinika.ru

Снимок публичных страниц сайта на 17.09.2026, опубликованный через GitHub Pages.

**Это витрина, а не рабочий сайт.** Формы, онлайн-запись и любые действия,
требующие сервера, здесь не работают — GitHub Pages отдаёт только статические
файлы, а сам сайт написан на PHP (Yii2).

Рабочий сайт: https://leoklinika.ru

Индексация поисковиками закрыта через robots.txt, чтобы копия не конкурировала
с основным сайтом в выдаче.

Исходный код сайта — в ветке `main`.
